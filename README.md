# Foglio di Preghiera

App statica in HTML, CSS e JavaScript per aggiornare mese dopo mese il calendario dei soggetti di preghiera.

## Come si usa

Apri `index.html` nel browser.

- Scegli mese e anno dalla barra in alto.
- Compila la colonna `Lettura` e la colonna `Soggetto di preghiera`.
- Il salvataggio e' automatico per ogni mese.
- `PDF` apre la stampa del browser, gia' impostata per A4 orizzontale.
- `Immagine` scarica un PNG ad alta risoluzione del foglio.

I dati vengono salvati nel `localStorage` del browser. Se cambi browser o cancelli i dati del sito, il foglio salvato in quel browser viene perso.
